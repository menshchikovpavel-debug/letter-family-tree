# Дерево букв

Интерактивная карта происхождения латинских букв: от сегодняшнего начертания назад, через
каролингский минускул, унциал, римский капитал, этрусский и греческий алфавиты, финикийское
и протосинайское письмо — до египетского иероглифа.

**Живая страница: https://menshchikovpavel-debug.github.io/letter-family-tree/**

Сейчас разобраны **A, B и C** — 50 узлов. У каждого узла: что за форма, когда и где бытовала,
что означала, код в Юникоде и ссылки на источники.

Одна страница без сборки и зависимостей: откройте `index.html` в браузере.

---

## Что показано

Выстроено как таймлайн: слева самое древнее, вправо — всё ближе к сегодняшнему дню.
Буква, какой она стала, стоит в конце строки справа и не уезжает при прокрутке.
Наведите на узел или коснитесь его.

Ряды — это ветви:

| ряд | что это |
|---|---|
| 0 | классический греческий — ветвь-родственник, не предок латиницы |
| 1 | ствол: прописные |
| 2 | книжное письмо, из которого вышли строчные |
| 3 | римский курсив |
| 4 | готика — тупиковая для антиквы ветвь |
| 5 | у C — ветвь G |

Колонки — шаги по времени, общие для всех букв. В данных колонка 0 — это сегодня,
колонка 13 — египетский иероглиф; на экране ось развёрнута, поэтому 13 рисуется слева,
а 0 справа (`layout()`, `n._cx = (MAXCOL - n.col) * colP + colP / 2`):

```
0  сегодня                 7  старая латынь
1  XV в., гуманисты        8  этруски
2  IX в., каролинги        9  западногреческий (+ ряд 0: классический греческий)
3  III–VIII, полуунциал   10  архаический греческий
4  IV–VIII, унциал        11  финикийский
5  рустичный капитал /    12  протосинайский
   новоримский курсив     13  египетский иероглиф
6  монументальный капитал /
   староримский курсив
```

## Начертания

Там, где знак есть в Юникоде, стоит настоящий символ, а не картинка:

| | |
|---|---|
| египетские иероглифы | `U+130FE` 𓃾 голова быка (F1), `U+13250` 𓉐 дом (O1), `U+13319` 𓌙 метательная палка (T14) |
| финикийское письмо | `U+10900` 𐤀 alf, `U+10901` 𐤁 bet, `U+10902` 𐤂 gaml |
| староиталийское (этрусское) | `U+10300` 𐌀, `U+10301` 𐌁, `U+10302` 𐌂 |
| греческий, латиница | `U+0391`…, `U+0041`… |

Коды сверены по `UnicodeData.txt` из UCD, а не по пересказам.

Протосинайского письма в Юникоде **нет** — заявка
[L2/19-299](https://www.unicode.org/L2/L2019/19299-revisiting-proto-sinaitic.pdf) ещё
обсуждается. Эти знаки и все палеографические начертания латиницы (рустичный капитал,
римский курсив, унциал, полуунциал, каролингский минускул, готика) нарисованы скелетными
контурами по описаниям и прорисовкам из источников. Это схемы начертания, а не факсимиле
почерка, и так прямо сказано на странице.

Шрифты — с Google Fonts: EB Garamond, Cinzel, Noto Sans Egyptian Hieroglyphs,
Noto Sans Phoenician, Noto Sans Old Italic, UnifrakturMaguntia.

## О достоверности

Этапы и даты взяты из источников, ссылка есть у каждого узла. Где наука расходится или данных
мало — это написано в самом узле, а не замазано. Например:

- Египетский предок во всех трёх случаях — гипотеза («возможно восходит»). По *gimel*
  источники спорят даже о том, что изображено: посох-праща, метательная палка или дубина.
- Египетский «алеф» — это гриф (G1), а не голова быка. Разные знаки, их часто путают.
- У беты «самое большое число резко расходящихся местных форм» из всех греческих букв
  (Jeffery, 1961), но словесных описаний этих форм в источниках нет — только прорисовки.
- Этрусские B, D, G и O есть в алфавите, но в этрусском языке нет звонких смычных, и буквами
  этими практически не писали. B проехала через этрусский как пассажир.
- Полуунциал — не производное от унциала: оба наследуют рустичному капиталу (по другой
  версии полуунциал идёт от позднеримского курсива).
- Для староримской курсивной `C` описания формы в источниках нет вовсе — в узле это сказано,
  а контур показан как схема по общему правилу «углы писались кривыми».
- Дату создания G источники дают по-разному: «около 230 г. до н. э.» и «вероятно, в III в.
  до н. э.»; атрибуция Спурию Карвилию Руге оспаривалась.

Основные источники: Wikipedia (A, B, C, G, Aleph, Bet, Gimel, Alpha, Beta, Gamma,
Proto-Sinaitic script, Phoenician alphabet, Archaic Greek alphabets, Old Italic scripts,
Etruscan language, Roman square capitals, Rustic capitals, Roman cursive, Uncial script,
Carolingian minuscule, Humanist minuscule, History of the Latin script) и кодовые таблицы
Unicode.

## Как устроен файл

Всё в одном `index.html`.

- `P = {…}` — словарь SVG-контуров, `viewBox 0 0 100 100`, только штрихи. 33 начертания.
- `SRC = {…}` — источники: `ключ: ['подпись', 'url']`.
- `DATA = […]` — по объекту на букву: `{ letter, rows, nodes, edges }`.
  - узел: `{ id, col, row, g, cap, t, m, d: [абзацы], u: 'U+…', s: [источники] }`
  - `g` — либо `S('ключ_из_P')` (рисунок), либо `U('символ', 'класс-шрифта', масштаб)`
  - `edges` — пары `[старший, младший]`; линии рисуются сами
- `layout()` считает раскладку: колонка — шаг по времени, ряд — ветвь. Верхний ряд сжат,
  в нём всего один узел.

## Как добавить следующую букву

1. Пройти цепочку по источникам: статья о самой букве, о финикийском предке, о греческой букве.
2. Сверить коды:
   `curl -s https://www.unicode.org/Public/UCD/latest/ucd/UnicodeData.txt | grep 'PHOENICIAN LETTER'`
   — не брать коды из Википедии, там их часто нет или они из пересказа.
3. Дорисовать недостающие контуры в `P`. Для проверки удобно собрать контактный лист:
   вытащить `P` и отрисовать все контуры по 120 px — мелкие ошибки видно только так.
4. Добавить объект в `DATA`, выдержав общую сетку колонок.

Развилки, которые стоит показать дальше: I/J, U/V/W, долгая ſ, Y и Z как поздние
заимствования из греческого.

## Оформление

Фон `#eeeeee`, текст `#1c1c1c`, карточка при наведении `#ffffff`. Больше ничего:
ни рамок, ни теней, ни градиентов, ни цветных акцентов. В тёмной теме страница
инвертируется, оставаясь двухцветной.
